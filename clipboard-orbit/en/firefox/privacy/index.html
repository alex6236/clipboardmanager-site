Privacy policy

Clipboard Orbit extension for Firefox · updated 24 November 2026

This policy covers the Firefox build of the extension. The policy for the Opera and Yandex Browser builds is on a separate page.

Clipboard Orbit runs on your computer and has no server. The extension does not collect, transmit or sell personal data.

What is stored

  • Clipboard history — text, links and images you copy. Stored in browser storage and the extension’s local database.
  • Settings — theme, pinned items, groups, snippets, download folder, capture options.
  • Service data — the chosen interface language and window state.

This data never leaves the device. The extension does not send it to a server and does not use cloud sync.

Screenshots, export and backups

Screenshots are saved as files to the browser’s Downloads folder; the subfolder is set in the extension settings. History export and automatic backup are JSON files on disk. Neither is uploaded by the extension.

Analytics and advertising

The extension contains no counters, ad modules or trackers. It does not read page content to send it anywhere and does not rewrite affiliate links.

Separately from the extension, this site page uses a Yandex Metrica counter (114086821). It counts page visits and UTM-tagged traffic. The extension itself contains no analytics and never receives clipboard data.

Feedback left on the uninstall page is sent to support@clipboardmanager.ru through FormSubmit (formsubmit.co, built by Devro LABS). The service receives the text and forwards it to us, keeping a copy for up to 30 days. The message contains the chosen reason, your comment if you wrote one, the page language and the time of sending. No name or email address is requested.

Permissions and why they are needed

PermissionPurpose
storageKeeps history, settings and snippets locally.
clipboardReadDetects what you copied so the item can be added to history.
clipboardWritePuts the selected item back into the clipboard.
alarmsRuns the daily local backup.
contextMenusAdds “Save as snippet” to the context menu.
scriptingAttaches the copy handler to tabs that were open before install or update.
tabsFinds the active tab to open the panel and the editor in the right place.
downloadsSaves screenshots and backups as files.
notificationsShows a notice when a screenshot is saved.
host_permissionsAuto-saving and the panel work on any site; page content is never transmitted.

Deleting data

Items can be deleted one by one or the whole history cleared in settings. Uninstalling the extension removes its local browser data; files saved to the Downloads folder remain on disk.

Policy changes

If the data handled changes, this page will be updated with a new date.

Contact

Questions about data and the extension: support@clipboardmanager.ru.
