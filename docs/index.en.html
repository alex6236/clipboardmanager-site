How to use ClipboardManager Plus

The program remembers everything you copy so you can paste what you need with one key. Below is every feature in order — from the first launch to templates, screenshots and backup.

First launch

After installation the program starts with Windows (this can be switched off) and lives in the notification area next to the clock. There is no main window on screen: the history opens with a hotkey.

  1. Press Ctrl+Shift+V — the history window opens next to the cursor.
  2. Copy a few text fragments in any application — they appear in the list.
  3. Select an entry with the arrow keys and press Enter — the text is pasted into the window you were working in.
  4. Press Esc to close the window without pasting.
Important. The program does not send your data anywhere. History is stored in a local file on your computer; the update check only transmits the current version number.

The main key and the plain-paste key can be changed in “Settings → Startup”, the template key is there as well, screenshot keys — in “Settings → Screenshots and images”. If a combination is already taken by another program, a warning appears next to the field.

History window

Categories are on the left, entries on the right. The search field at the top filters the list as you type.

Built-in sections

  • All entries — the full history in copy order.
  • Pinned — what you marked as important; these entries are never removed by the retention limit.
  • Quick slots — up to nine entries pasted with Ctrl+Shift+1…9.
  • Uncategorised — entries without a category.
  • Images — copied pictures and screenshots.
  • Templates — text snippets Pro.
  • Trash — deleted entries that can still be restored.

Your own categories follow below; create, rename and delete them through the “Categories” menu. A category can be pinned — then every entry inside it is lifted to the top just like a pinned entry.

Hovering an entry shows a card with the full text; it can be turned off in “Settings → Storage”. The same page holds sorting by usage count and “pinned entries on top”.

The “View” menu controls the entry timestamp, collapsing the category pane and the dark theme.

Working with entries

Every action is available from the “Edit” menu and from the right-click context menu.

  • Paste — copy the entry and send it to the active window.
  • Copy — put the entry on the clipboard without pasting.
  • Paste and delete — paste and immediately drop the entry from history.
  • Paste selected together — select several entries (Ctrl+click or Ctrl+A) and paste them as one block, each on its own line.
  • Pin / unpin — protects the entry from the retention limit and lifts it to the top.
  • Edit — change the text right in the history.
  • View — a separate window for long text or a picture.
  • Move to category / Remove from category — sorting history into folders.
  • Add to quick slots / Remove from slots — bind the entry to Ctrl+Shift+digit.
  • Move up / down — manual order in the list.
  • Delete — sends the entry to the trash.
  • Paste as… — Pro: paste in upper or lower case, capitalised, without extra spaces or without line breaks.
Double-clicking an entry does the same as Enter. With “Close window after pasting” enabled the window hides right after the text is sent.

Quick menu at the cursor

Ctrl+Shift+Alt+V opens a compact list of recent entries right where the cursor is. Double-click or Enter pastes the entry into the window that was active before the menu opened, Esc closes the list.

It is handy when you do not want to close what you are doing just to paste one of the last fragments.

Templates and variables Pro

A template is a piece of prepared text that is pasted as a whole and can insert the current date, time and user name. Open templates via “Edit → Templates”, with Ctrl+Shift+Alt+S, or from the tray menu.

What the template editor offers

  • Name, group and template text.
  • Variable buttons that insert a placeholder at the caret.
  • Template groups: create, rename, move and delete.
  • Ctrl+Enter — save the template.

Variables

VariableInserts
{date} or {d}The current date, e.g. 11.11.2026
{time} or {t}The current time, e.g. 14:05
{datetime}Date and time together
{year}The current year
{user} or {username}The Windows user name

Variables are resolved at paste time, not when the template is created, so the same template always yields fresh date and time. Unknown braces are left untouched.

Screenshots

Three modes start with PrtScr, Alt+PrtScr and Shift+PrtScr. If the system already owns PrtScr, the program reports it and assigns the area capture to Ctrl+Shift+Alt+P.

Editor

After selecting an area, the annotation editor opens: hand to move the selection, arrow, pencil, line, rectangle, text, step numbering and blur. Colour and thickness are chosen on the toolbar.

In “Settings → Screenshots and images” you can hide the editor, enable automatic saving into a chosen folder and decide whether “Done” also copies the snapshot to the clipboard.

Image files are removed from disk only when the entry is permanently deleted from the trash — while an entry can be restored, its picture stays in place.

Images

Pictures copied in a browser or an image editor land in the “Images” section and are kept together with the text history. Open such an entry with “View” — it offers zoom and a “Fit” mode.

With “Save copied images to a folder” enabled, every copied picture is additionally written to the chosen directory.

Trash and retention

Deleting an entry does not erase it: it goes to the trash and stays there for the configured number of hours (24 by default). The trash offers “Restore”, “Delete permanently” and “Empty trash”.

“Settings → Storage” controls:

  • Retention in days — 0 by default, meaning forever. Pinned entries are exempt.
  • Trash lifetime in hours.
  • Keep repeated copies — by default a repeat does not create a new row but lifts the existing one.
  • Wheel scrolling — how many rows one notch scrolls.
  • Show the entry category in the list.

Application filter in the “Clipboard” section lets you either record copies only from listed programs or ignore them. The list is given as process names separated by semicolons, e.g. WINWORD.EXE;EXCEL.EXE.

Backup Pro

History, categories, pinned entries, quick slots and templates are exported into a single JSON file. Export and import are available in two places: “File → Export to JSON / Import from JSON” and “Settings → Advanced → Backup”.

Import never duplicates: entries already present in history are skipped. Before moving to a new computer, save a copy on the old one, transfer the file and run the import.

Updates

Once a day the program asks for the latest version number. Nothing is downloaded or installed automatically — when a new version exists you are offered to open the download page.

Check manually via “Help → Check for updates”, turn it off in “Settings → Advanced”.

Activation

  1. Open “Settings → Activation” (or “Help → Activation”).
  2. Copy the device ID — it is needed to obtain a key for this computer.
  3. Paste a key like CMGR-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX and press “Activate”.

The key is verified offline, no internet required. A regular key is bound to one computer; a retail key works on any PC. When a key does not fit, the program distinguishes wrong format, invalid key, key issued for another computer and revoked key. Deactivation releases the key on this device.

Where data lives

  • Regular installation: the history database and settings file live in your user profile — %USERPROFILE%\.clipboard_manager.db and %USERPROFILE%\.clipboard_manager.db.ini.
  • Portable mode: when a portable.txt file sits next to ClipboardManager.exe, data moves into the data folder beside the program — handy for a USB stick.
  • Screenshots and images go to the folder chosen in settings; in portable mode the default is data\screenshots.

FAQ

The hotkey does not work

The combination is most likely taken by another program. Open “Settings → Startup” and assign another one; a message appears next to the field when the keys are already in use.

Pasting goes to the wrong window

Windows forbids sending input to programs running as administrator from a normal-privilege process. If the target application runs elevated, start ClipboardManager as administrator or paste through the clipboard (Ctrl+V).

Old entries disappeared

Check the retention period and trash lifetime in “Settings → Storage”. Pinned entries are never removed by retention — pin what matters.

PrtScr combinations do not work

Another program or a Windows feature may own the key. The program reports this and suggests an alternative; change the keys in “Settings → Screenshots and images”.

The key is rejected

Make sure the whole key was copied and that it was issued for this device ID. Retail keys are not bound. If the key was revoked, contact support.

The program does not start after an update

Close it from the notification area and start it again. If that does not help, contact support and attach the log file from the data folder.
